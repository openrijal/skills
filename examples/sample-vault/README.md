# Sample vault

A throwaway demo vault in the IPARAW layout. Everything in it is fictional. "Sam Rivera", "Widget API", and every link are made up. Nothing here comes from a real person's activity.

Open it in Obsidian (or any Markdown tool) to see where files go:

- `AGENTS.md`: the vault guide an agent reads.
- `4-Archives/Logs/Daily/2026-03-10.md`: one sample daily log, as the `daily-log` skill would write it.
- `0-Inbox/`, `5-Wiki/`: empty on purpose. The Inbox is for human review. The wiki is built later by `wiki-synthesis`.

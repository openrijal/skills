# My daily-log rules

The runner reads this file word for word. Write whatever you want here, in plain language.

- Write in the first person, in short plain sentences, with no filler.
- Link PRs, tickets, and commits instead of pasting their contents.
- Keep anything personal or about family out of the note.
- Never copy secrets, tokens, or customer data into a note.
- On weekends, write a light summary or skip the day.
- Carry unchecked items from yesterday's Open loops into today's.

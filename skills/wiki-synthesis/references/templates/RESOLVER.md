# Resolver

Where things are filed in this wiki. Read before creating a page. Walk the list in order and stop at the first match.

1. A named person you work with repeatedly: `people/`
2. A company, team, or community: `organizations/`
3. Something being built, with a repo, spec, or team: `projects/`
4. A choice that was made, with a date and a reason: `decisions/`
5. A mental model or theme you would teach: `concepts/`
6. None of the above: do not file it. Mention it in the run report for a person to decide.

One page per entity. If two folders seem to fit, the earlier one is the primary home. Use links to show the other relationship.
